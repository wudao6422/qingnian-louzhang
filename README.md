# 青年楼长成长记

一款像素风的可视化互动叙事小游戏。玩家扮演一名大学生志愿者，在社区网格的日常里做选择，从普通志愿者一路成长为楼长队伍的副队长或总队长。

技术上是**纯原生 HTML / CSS / JavaScript**，单个 HTML 文件承载全部游戏逻辑，零依赖、零构建。双击就能玩，也可以直接部署到 GitHub Pages 在线访问。

> 本作品为虚构创作，人物、社区与情节均为虚构，仅用于展示社区志愿服务的工作逻辑与青年成长路径，不指向任何真实人物、社区或组织。

---

## 玩法

- 剧情按「事件 → 内心 → 选择」的节奏推进，先读发生的事，再读主角的内心，最后做决定。
- 每个选择都会改变主角的属性，属性决定后续机遇与最终结局。
- 走完四个阶段，达成晋升，或触发某一种结局。

剧情节点分四类：日常（daily）、月度（monthly）、人际（interpersonal）、特殊（special，高风险节点）。

## 四个阶段

```
普通志愿者 → 小队长 → 副队长 / 总队长
```

- **普通志愿者**：线上舆情监测与线下社区服务，打基础。
- **小队长**：带组、分派任务，至此解锁管理属性。
- **第三年二选一**：
  - **副队长**：对内内务线，月报汇总、台账质控、经验沉淀、内部带教。
  - **总队长**：对外全局线，对接指导老师、会议统筹、项目发展、全域自运转、战略提案。

## 属性系统

7 项可见属性 + 1 项隐藏属性。

| 属性 | 含义 |
| --- | --- |
| 信息敏锐 | 识别舆情、抓住关键信息的敏锐度 |
| 决策判断 | 在信息不全时作出判断的能力 |
| 沟通表达 | 与居民、组员沟通的表达力 |
| 居民信任 | 居民对志愿者的信任程度 |
| 统筹规划 | 管理岗属性，晋升小队长后启用 |
| 组织协调 | 管理岗属性，晋升小队长后启用 |
| 对外联络 | 管理岗属性，晋升小队长后启用 |
| 公益初心 | 隐藏属性，全程只显示星级，晋升小队长那一刻才第一次亮出真实数值 |

晋升判定：公益初心达到阈值、居民信任达标、且没有高危节点的负面记录。

## 特色功能

- **结局收集册**：6 种结局跨周目永久累积（含中途掉队与走到任期终点），封面、结局页、菜单三处入口。
- **换个岗位再来一次**：走完一条晋升支线，解锁另一条支线的「直达」入口，跳过前两章直接体验另一条线。
- **进度存档**：localStorage 自动保存，支持继续上次进度与重新开始。
- **沉浸细节**：像素字体、背景音乐，以及点击、颁奖、打字三类音效，音乐与音效可分别开关。

## 技术栈

- 纯原生 HTML + CSS + JavaScript，无框架、无构建、无外部依赖
- 单文件游戏逻辑：`index.html`
- hash 路由管理页面切换
- localStorage 存档，进度、结局收集册、支线解锁、音效偏好各自独立键值
- 像素素材 + Fusion Pixel 子集字体

## 本地运行

直接用浏览器打开 `index.html` 即可游玩。

若希望通过 HTTP 访问（推荐，可避免个别浏览器对本地文件的限制）：

```bash
python -m http.server 8000
# 然后浏览器打开 http://localhost:8000
```

## 目录结构

```
.
├── index.html              # 游戏本体：全部剧情数据与逻辑
├── assets/
│   ├── img/                # 像素素材：立绘 / 头像 / 图标 / 徽章 / 场景
│   ├── font/               # Fusion Pixel 子集字体 + OFL 授权
│   └── audio/              # 背景音乐 + 三类音效
├── _build/                 # 素材与字体的处理脚本、自动化测试
│   ├── *.py                # 切图、量化、字体子集化、剧情注入脚本
│   └── tests/*.js          # 存档 / 结局 / 支线 / 音效 / 阅读流程回归测试
├── LICENSE                 # 代码授权（MIT）
└── README.md
```

## 部署到 GitHub Pages

1. 把本仓库推送到 GitHub。
2. 仓库 **Settings → Pages**，Source 选择 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`。
3. 保存后访问 `https://<你的用户名>.github.io/<仓库名>/` 即可在线游玩。
